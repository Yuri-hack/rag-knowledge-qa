## 三个裁决性结论

**1. S01 是唯一被 agent 独占修复的题（架构贡献的隔离证明）**
同样提示词、单次检索（B）= WRONG；调大 K（A′）= WRONG（clean-flush 重跑后 MA01 类题反而 0/5——更多噪声稀释）；只有循环+冲突显式化（C）= CORRECT。"只是提示词的能力"和"调大召回数就行"两个质疑都被数据否定。

> 【2026-10-12 复验 + 机器重判，结论范围收窄】两层证据都指向同一方向：
> ① 语料升 v1.1 后 S01 双臂复验 **baseline 与 agent 均 CORRECT**（`s01-v11-*-judged-*.json`）——scope anchors
> 让基线直接答对（10天，并主动对比总部8天）；② 机器重判（见文末"机器重判凭证"节）显示历史 S01 裁决与
> 实际答案不符——**B 并非"沉默答8"，它显式讨论了 C01 与对照表的冲突**，按现行判分应判可接受。
> **"S01 是 agent 独占修复"正式退役**：检索层一处 scope anchor（语料工程）干掉了架构补偿（6.8k tokens）的价值。
> 站得住的差异化证据：MA01/AG02 关键词层数字（C=4/5 vs A′=0/5）、成本（6.8k vs 2.0k）、
> **多轮指代（D6 已验收 2/7 vs 7/7）**、**范围外拒答（W01 机器凭证：prompt 规则带来 B/C CORRECT vs A/A′ WRONG）**、框架（D7）。

**2. 调大 K 的真相（A′ clean 重跑）**
topK=30 在 MA01 上 0/5，比 topK=10 的 2-3/5 更差——15 条混合 context（9 条子公司/旧版/驻场噪声）稀释了有效证据。**大 K 是全局税：26 题全部 ~4.5k tokens（2.3 倍），换不来难题的正确率。**

**3. 最终工程决策：按题路由（数据版）**
```
简单事实题（single_hop/version/scope非冲突）→ 基线（1.7k tokens，2.4s，95%）
多主体对比/冲突消歧/需要可审计性      → agent（6.8k tokens，但 S01 唯一正确解）
未来扩展（多轮/联网/文档级修复）      → agent（结构能力，基线无法添加）
```
