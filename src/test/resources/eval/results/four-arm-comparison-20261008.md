## 三个裁决性结论

**1. S01 是唯一被 agent 独占修复的题（架构贡献的隔离证明）**
同样提示词、单次检索（B）= WRONG；调大 K（A′）= WRONG（甚至用多出来的上下文做出更自信的错误推理）；只有循环+冲突显式化（C）= CORRECT。"只是提示词的能力"和"调大召回数就行"两个质疑都被数据否定。

**2. 但 agent 没有全面超越基线**
facts 覆盖 92% vs 95%，成本 3.5 倍。agent 的正确率优势仅体现在 1-2 道题（MA01 +1 fact、S01 质变）。抽检还发现关键词层**高估了基线**（MA02/AG02 假阳性：旧版数字字样骗过了子串匹配）——两层判定制的方法论价值第二次被实证。

**3. 最终工程决策：按题路由（数据版）**
```
简单事实题（single_hop/version/scope非冲突）→ 基线（1.7k tokens，2.4s，95%）
多主体对比/冲突消歧/需要可审计性      → agent（6.8k tokens，但 S01 唯一正确解）
未来扩展（多轮/联网/文档级修复）      → agent（结构能力，基线无法添加）
```
